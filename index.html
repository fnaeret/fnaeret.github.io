Project Overview

Five Nights at Epstein's is a FNAF fan game released on itch.io in January 2026. Built in Unity by an anonymous developer, it swaps the animatronics for figures tied to the Epstein case and drops the player on Epstein Island. The game went viral on TikTok and YouTube through February 2026 before the creator pulled it from itch.io later that month. This project decompiles the original build and documents what remains.

Technical Goals

  • Asset Preservation Extracting models, textures, audio, and other game data and saving them in open formats.
  • Full Documentation Annotating each reversed function and data structure so the codebase stays readable.
